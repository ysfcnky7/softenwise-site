S70.1| **Secrets Extraction:** Extract all hardcoded credentials, API keys, JWT secrets, connection strings, and private keys into `.env` files.

S70.3| **Environment Security:** Ensure `.env*`, `*.pem`, `*.key`, `*.keystore`, and `google-services.json` are strictly added to `.gitignore`.
S70.4| **Client-Side Secret Shielding:** Never store or expose private API keys (e.g., Stripe Secret Key, AWS Access Key, database credentials) inside Web or Mobile client-side code. Use dedicated backend proxy endpoints for external integrations.
S70.5| **Password Hashing:** Hash passwords using Argon2id or bcrypt (minimum work factor 12). Never use MD5, SHA-1, or plain SHA-256.
S70.6| **JWT Security & Rotation:** Use short-lived Access Tokens (e.g., 15 mins) and long-lived, single-use Refresh Tokens with automatic token rotation and revocation list in Redis.
S70.7| **Cookie Hardening:** Set cookies with `HttpOnly`, `Secure`, `SameSite=Strict`, and explicit `Domain`/`Path` attributes.
S70.8| **Rate Limiting & Brute-Force Protection:** Implement IP-based and user-based Rate Limiting (Redis Sliding Window or Token Bucket) on critical routes (`/login`, `/register`, `/forgot-password`, `/verify-otp`, `/reset-password`).
S70.9| **Multi-Factor Authentication (MFA/2FA):** Enforce TOTP / WebAuthn support for elevated actions and administrative accounts.
S70.10| **Account Lockout:** Temporarily lock accounts after N consecutive failed login attempts to prevent brute-force attacks.
S70.11| **Session Termination & Invalidation:** Invalidate server-side sessions instantly on logout, password change, or suspicious activity.
S70.12| **Account Deletion (GDPR/KVKK Compliance):** Ensure "Delete Account" permanently purges or anonymizes all user PII from Primary DB, Redis Caches, S3 Buckets, and 3rd-party analytics.
S70.13| **Server-Side Authorization (BOLA/IDOR):** Validate user ownership and resource context strictly on the backend API layer. Never trust client-provided IDs without verifying if `request.user.id == resource.owner_id`.
S70.14| **RBAC & ABAC:** Enforce Role-Based Access Control and Attribute-Based Access Control on administrative, financial, and management endpoints.
S70.15| **Private Storage & Storage ACLs:** Keep cloud buckets (AWS S3, Azure Blob) private by default. Access files via time-limited Signed URLs / Pre-signed GET-PUT operations.
S70.16| **Mass Assignment Protection:** Use DTOs (Data Transfer Objects) / White-listing on incoming requests to prevent model binding pollution (e.g., users setting `isAdmin = true`).
S70.17| **Strict Schema Validation:** Validate incoming request payloads, headers, query parameters, and route params using strict schemas (Zod, FluentValidation, Joi, Dantic). Reject extra/unknown properties.
S70.18| **SQL Injection & NoSQLi Protection:** Use Parameterized Queries or ORM (EF Core, Prisma, Dapper, TypeORM) exclusively. Prohibit raw dynamic string concatenation inside raw database queries.
S70.19| **XSS & Contextual Output Encoding:** Escape all user-generated content rendered in HTML/React DOM. Sanitize HTML input with DOMPurify if HTML rendering is mandatory.
S70.20| Enforce file extension whitelisting (never trust user file extensions).
S70.21| Validate file headers / magic bytes (e.g., check PNG signature `89 50 4E 47`).
S70.22| Enforce maximum file size limits on reverse proxy and app layers.
S70.23| Strip EXIF / GPS metadata from uploaded images.
S70.24| Store files using UUID-generated filenames outside the web root directory.
S70.25| **SSRF (Server-Side Request Forgery) Mitigation:** Validate and whitelist destination URLs before making outbound HTTP requests from the server. Block internal IP ranges (`127.0.0.1`, `10.0.0.0/8`, `192.168.0.0/16`, AWS IMDS `169.254.169.254`).
